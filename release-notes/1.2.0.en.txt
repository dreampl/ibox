The app is now IBOX. Connections must pass real data before they count as connected; when a server is blocked, IBOX finds a way around it by itself (encrypted DNS, clean Cloudflare addresses for CDN configs, other TLS fingerprints) and remembers what worked on each network. New Usage page: data cap per Persian or calendar month, use per app and per site, alerts, Eco mode (updates and telemetry blocked inside the tunnel), speed limits, smarter gaming mode, workplace networks and signed company policies. Windows/Linux: TUN mode also sets the system proxy for apps that check it. Linux: manual routing rules. Phone: new navigation bar, QR code scanning, springy animations. A damaged database is now repaired at start.
