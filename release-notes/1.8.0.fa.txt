IBOX ۱.۸.۰ (ویندوز)

جدید
- قفسهٔ ناچ: فایل، پوشه، برنامه، متن، لینک یا عکس را روی ناچ بکشید؛ با بردن موس روی ناچ آن‌ها را ببینید و بیرون بکشید تا هر جا رها کردید کپی شود.
- ناچ به لبهٔ بالای صفحه چسبیده و با فیزیک واقعی کش می‌آید: به سمت آیتمِ در حال درگ متمایل می‌شود، با رها شدن آیتم موج برمی‌دارد و هنگام بیرون کشیدن، آیتم را کمی نگه می‌دارد و بعد رها می‌کند.
- نوتیفیکیشن‌های Claude و ChatGPT با آیکون برنامه کوتاه روی ناچ نشان داده می‌شوند.
- اجازه‌گرفتن‌های Claude Code و Codex روی ناچ می‌آید (Allow / Deny / Answer there): تنظیمات ← Notch ← Connect Claude Code / Connect Codex. در Codex یک بار ‎/hooks را بزنید و هوک‌های IBOX را trust کنید.

رفع اشکال
- ناچ موقع کوچک شدن دیگر کمی بزرگ نمی‌ماند و بعد نمی‌پرد.
- ناچِ کم‌رنگ با کمی مکث موس سریع پررنگ می‌شود.
