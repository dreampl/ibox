## Runtime checks still needed

The deletion crash regression ran headlessly on Windows against the Linux UI code. Installation and interactive rendering on a Linux desktop, real Claude/Claude Code traffic and Iranian direct routing on the affected network, A54 installation, and real phone-to-desktop remote commands have not been verified on the user's hardware. A Windows preview exposed the new controls through accessibility inspection, but its screenshot/activation check was inconclusive; a full visual review is still needed.

Remote control requires the new version on both devices, local opt-in on the target, network access and a running app. It does not wake an OS-stopped app. Android VPN permission must first be granted locally. Device status is polled every 15 seconds; commands expire after 120 seconds.

Nex Family management requires explicit Telegram numeric-ID assignment and permissions in the relay. The panel integration contract and deployment adapter are in `server/README.md`, also copied to `G:/amesterdam/deploy-2026-11-28-ibox-control`. The concurrent panel UI was not edited. Future panel deployments must retain the account-control adapter and route integration.

Telegram identity is limited to fields supplied and verified by the existing login service. Optional contact sharing controls phone availability. Full configuration secrets and Telegram session credentials are not uploaded.
