IBAR 2.1 — راهنمای نصب
======================

۱) خود IBAR
   فایل IBAR-2.1.0-win-x64.msi را اجرا کنید. فقط برای کاربر فعلی نصب می‌شود (بدون پیغام مدیر سیستم) در
   %LOCALAPPDATA%\Programs\IBAR، همراه ویندوز اجرا می‌شود و در منوی Start می‌آید. نسخهٔ قبلی را به‌روز می‌کند.
   تنظیمات: کلیک روی آیکن IBAR در tray.

۲) دانلودهای مرورگر با حجم دقیق (اختیاری)
   بدون افزونه هم IBAR دانلودها را از روی فایل موقتشان می‌بیند (حجمِ دریافت‌شده و سرعت، بدون درصد).
   با افزونه، خود مرورگر نام، حجم کل، درصد و سرعت را می‌دهد. نصاب، host محلی IBAR را برای Chrome، Edge، Opera،
   Brave و Firefox (فقط برای کاربر فعلی) ثبت کرده است.

   Chrome / Edge / Opera / Brave
     تنظیمات IBAR > کارها روی ناچ > «نصب افزونه · نام مرورگر»: صفحهٔ افزونه‌های مرورگر و پوشهٔ افزونه
     (%LOCALAPPDATA%\Programs\IBAR\extensions\chromium) باز می‌شود. Developer mode را روشن کنید، Load unpacked
     را بزنید و همان پوشه را انتخاب کنید. (همین فایل‌ها در ibar-downloads-chromium-2.1.0.zip هم هست.)
     شناسهٔ افزونه ثابت است: nhcbmjechdfcppfefbmhmanmbepahnpi و host فقط همین افزونه را می‌پذیرد.

   Firefox
     افزونه امضای Mozilla ندارد، پس Firefox معمولی آن را فقط تا بستن مرورگر نگه می‌دارد:
     about:debugging > This Firefox > Load Temporary Add-on > ibar-downloads-firefox-2.1.0.xpi
     نسخه‌های Developer Edition / Nightly می‌توانند دائمی نگهش دارند (xpinstall.signatures.required = false).

   چیزی که افزونه می‌فرستد: نام فایل (بدون پوشه)، حجم، وضعیت، سرعت، نام مرورگر و دامنهٔ منبع.
   هرگز آدرس کامل یا تاریخچه. فقط با host همین کامپیوتر حرف می‌زند (بدون شبکه و بدون پورت محلی).

۳) پل Adobe (اختیاری، آزمایشی)
   ibar-adobe-bridge-2.1.0.zip یک افزونهٔ CEP بی‌امضاست (وضعیت صف رندر After Effects / Premiere، ذخیره و خروجی
   Photoshop). راهنمای داخلش را ببینید. افزونهٔ CEP بی‌امضا فقط با کلید PlayerDebugMode در تنظیمات Adobe بار
   می‌شود که تصمیمش با شماست. بدون آن هم IBAR پنجره‌های پیشرفتِ برنامه‌های Adobe و لاگ Media Encoder را دنبال می‌کند.

۴) اعلان‌های ویندوز روی ناچ (اختیاری)
   تنظیمات IBAR > اعلان‌های ویندوز. هر برنامه بعد از اولین اعلانش در فهرست می‌آید؛ هرکدام را بخواهید تیک بزنید.
   ویندوز باید اجازهٔ خواندن اعلان‌ها را داده باشد (Settings > Privacy > Notifications).

۵) چت
   از Claude Code یا Codex خودتان استفاده می‌کند. اگر گفت Claude Code وارد نشده، یک بار «ورود» را بزنید
   (یک کنسول باز می‌شود؛ /login را بنویسید).

۶) برای برنامه‌نویس‌ها
   IBAR-API.md: برنامه‌های دیگر (مثل Alita) چطور کار، اعلان و صدا روی ناچ نشان دهند (Python / Go / Rust).

حذف: Settings > Apps > IBAR > Uninstall (ثبت host هم حذف می‌شود).
