Installing IBOX 2.3.5

Windows 10/11 x64:
Install IBOX-2.3.5-win-x64.msi. Administrator access is needed for the TUN service; no separate .NET installation is required. Open IBOX from Start.

Android 10+:
Install the APK matching the device ABI. Samsung A54 and most recent phones use IBOX-2.3.5-android-arm64-v8a.apk. Approve VPN permission locally on first connection.

Linux x64:
sudo apt install ./ibox_2.3.5_amd64.deb
ibox gui

Linux archive:
mkdir -p ibox-2.3.5
tar -xzf ibox-2.3.5-linux-x64.tar.gz -C ibox-2.3.5
./ibox-2.3.5/opt/jackivpn/jackivpn gui

First connection:
Telegram sign-in is optional. Add a subscription or config, choose a server or enable Smart Connect, then press Connect. Windows subscription management is under Servers > Subscriptions.

Devices & Nex Family:
Install 2.3.5 on both devices and enable remote control on the target. The target app must remain running with network access. Family access requires assigned verified Telegram IDs and provider permissions.

Notch shortcut: Ctrl+Alt+I on Windows and Linux X11. Close sidebar: Esc.
Checksums: SHA256SUMS.txt. Full instructions: README.md at https://github.com/dreampl/ibox
