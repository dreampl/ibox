Installing IBOX
====================

Windows 10 / 11 (64-bit)
------------------------
1. Run JackiVpn-<version>-win-x64.msi.
2. If Windows shows "Windows protected your PC", click More info > Run anyway (the app is not yet signed with a
   commercial code-signing certificate).
3. Click Install and accept the administrator prompt. The app goes to Program Files and its privileged service
   (TUN mode, kill switch) is registered and started automatically. No .NET installation is needed.
4. Open the app, add your subscription link under Subscriptions (or import configs under Servers), and connect.
Uninstall: Windows Settings > Apps > IBOX > Uninstall.

Apps that read the system proxy only when they start (e.g. Claude Desktop): after switching to IBOX from
another client, restart them once. TUN mode does not have this issue.

Android 10 or later
-------------------
1. Install the APK that matches the phone:
   - ...-android-arm64-v8a.apk    almost every phone from recent years (pick this one if unsure)
   - ...-android-armeabi-v7a.apk  very old 32-bit phones
   - ...-android-x86_64.apk       emulators
2. Allow "install unknown apps" for the app you opened the file with if Android asks. If Play Protect warns,
   choose More details > Install anyway.
3. Open the app, paste your subscription link under Subscriptions and tap Add, then tap the connect button on
   Home and accept Android's VPN request.
4. Kill switch: Settings > Open Android VPN settings > gear next to IBOX > turn on "Always-on VPN" and
   "Block connections without VPN".

Linux (Ubuntu / Debian, 64-bit)
-------------------------------
1. Install the package: sudo apt install ./jackivpn_<version>_amd64.deb
   (or unpack jackivpn_<version>_amd64.tar.gz anywhere and run ./jackivpn from it).
2. Open IBOX from the applications menu (or run: jackivpn gui). The package gives sing-box the network
   permission TUN mode needs, so no sudo is needed to connect. (From the .tar.gz, the first TUN connect asks
   for your password once.) Dual VPN over IPsec uses NetworkManager's plugin: network-manager-l2tp or
   network-manager-strongswan.
3. Add your subscription link under Subscriptions and connect.
Uninstall: sudo apt remove jackivpn

New in 2.1.0
------------
- Stability: apps are protected when the connection drops, and IBOX keeps reconnecting until it is back.
- About 20 MB of memory in the tray; flat look without borders, shadows or gradients; Android connects again.

New in 2.0.0
------------
- IBAR: the notch as an app of its own, on every monitor (glass, plugins, chat, Claude / ChatGPT circles).
  Install it from IBOX → Settings → Notch → Install IBAR, or run IBAR-2.0.0-win-x64.msi (no administrator rights).
- Linux: whole-system mode asks for the password once, when IBOX opens.
- IBOX uses about a third of its former memory while in the tray.

New in 1.7.0
------------
- Dual VPN can be on alone (it then carries all traffic); with IBOX on too, only the company's part takes it.
  Smart scope (IBOX decides) or your own list of names and subnets: Servers > Dual VPN > Edit.
- 10 cartoon avatars for profiles (Windows, Linux); Alita is treated as a friend (Settings).
- Android: the notch reaches the camera hole.

New in 1.6.0
------------
- Dual VPN on its own (WireGuard, IPsec, Kerio, or the company's VPN app): Servers > Add Dual VPN.
- Move your account to another device as one password-protected .ibox file (Windows, Linux, Android).
- A short first-start tour (again from About); much smoother Windows app; Linux fixes (subscriptions in TUN
  mode, one password prompt, notch).

New in 1.5.0
------------
- Profiles with their own encrypted settings (avatar at the bottom of the side bar).
- Dual VPN in Work mode: Usage > Workplace > Dual VPN.
- Node-based routing editor in the browser: Routing > Node editor.
- DNS: smart, the network's own, or your own (also DNS-over-HTTPS); DNS per network adapter (DNS page).
- AI agents (Claude…) through MCP or the ibox-ctl command line: Settings > AI agents (off by default).
- Now playing in the notch; Linux gets the new look and the notch.

New in 1.0.0
------------
- New phone design and Persian language (Settings > Language).
- Automatic, signed updates from connect.jackiairline.ir (Windows: banner at the top; phone: Settings > Updates).
- Subscription updates no longer duplicate servers (earlier duplicates are cleaned up automatically).
- Server list grouped by subscription.
- XHTTP and custom-path gRPC configs now work on phones too, and keep working after the first connection.
- The connect button turns magenta while gaming and light blue while streaming (also shown in the phone notification).
- PasarGuard subscriptions: device limit and last-online time, every 10 minutes.
- Sync device: Subscriptions > Sync device (app open on both devices, same Wi-Fi).
- Internet stuck? Start menu > "IBOX - Emergency network restore".
File integrity: SHA-256 hashes are listed in SHA256SUMS.txt.
