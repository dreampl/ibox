# 📦 IBOX 
*(Formerly Jacki VPN)*

**A Next-Generation Network Toolkit & Advanced Proxy Client**

IBOX is a comprehensive, cross-platform network manager designed for maximum stability, privacy, and performance. Built with a modern, minimalist interface, it offers intelligent routing, dynamic network modes, and robust encryption to seamlessly bypass severe network restrictions.

## ✨ Key Features

### 🛡️ Advanced Security & Connectivity
* **Reality Protocol Optimization:** Engineered for rock-solid, uninterrupted connections even under the most restrictive network environments.
* **Handshake Encryption:** Implements advanced cryptographic handshakes to protect initial connections from Deep Packet Inspection (DPI) and interception.
* **DNS Search Boost:** Radically optimized DNS resolution engine to minimize lookup times, lower ping, and accelerate overall browsing speeds.

### 🎛️ Traffic Control & Management
* **Smart Network Modes:** Instantly adapt your connection behavior with 5 tailored profiles: 
  * 🌐 `Normal` - Balanced daily use
  * 🌱 `Eco` - Battery and data saving
  * 🎮 `Gaming` - Ultra-low latency priority
  * 📺 `Streaming` - High bandwidth, unthrottled media
  * 💼 `Work` - Maximum stability and secure routing
* **Custom Rule Maker:** A powerful, intuitive engine to create custom routing rules, allowing granular control over which apps or domains use the proxy.
* **Net Usage Manager:** Built-in, real-time analytics to track and manage your data consumption accurately.

### 🔄 Ecosystem & UX
* **Local Network Sync:** Seamlessly synchronize configurations, nodes, and settings across all your devices connected to the same local network.
* **Next-Gen UI & Notch Control:** A completely overhauled, elegant, and minimal interface (featuring modern design aesthetics). Includes intelligent Notch Control for a flawless, edge-to-edge experience on modern smartphone displays.
